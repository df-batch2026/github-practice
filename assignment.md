# 🎮 Git + GitHub + Vercel: Let's Build a Game!

Hey everyone! 🚀

This time, instead of practicing Git on simple text files, let's build something fun!

Your task is to build a small browser game, manage the project using Git and GitHub, and deploy it on Vercel so that anyone can play it using a live URL.

## 🕹️ The Challenge

Build a **Guess the Number** game.

The computer will select a random number, and the player has to guess it. Add hints like "Too High!" or "Too Low!" until the player finds the correct number.

You can make the game as creative as you want!

Some ideas:
- Add a score and attempt counter.
- Add Easy, Medium, and Hard difficulty levels.
- Add a restart button.
- Improve the UI with animations, colors, and sound effects.
- Add a timer or a high-score feature.

## 🛠️ Let's Use Git Along the Way

**1. Start your project**
- Create a local repository.
- Add your HTML, CSS, and JavaScript files.
- Make your first commit.

**2. Track your changes**
- Modify the game and explore `git diff`.
- Stage and commit your changes.
- Try `git commit --amend` to correct your latest commit.

**3. Explore Git history**
- Use `git log` and `git log --oneline`.
- Explore your commit history with `git log --graph --oneline --all`.

**4. Create a feature branch**
- Create a branch called `feature/game-ui`.
- Improve the game's design on this branch.
- Create another feature branch for something like scoring or difficulty levels.
- Merge your features into `main` and explore merge commits.

**5. Add a version tag**
- Once your game is ready, create an annotated tag such as `v1.0.0`.

**6. Connect to GitHub**
- Create a GitHub repository.
- Connect your local repository using a remote.
- Push your commits and tags.
- Make a change on GitHub and use `git pull` to bring it into your local repository.
- Make another local change and push it back.

**7. Deploy on Vercel 🌐**
- Import your GitHub repository into Vercel.
- Deploy your game.
- Open the live URL and test it in your browser.

## 🎉 Final Result

By the end, you should have:

- A playable browser game.
- A Git repository with meaningful commits, branches, a merge commit, and a tag.
- Your code hosted on GitHub.
- A live game deployed on Vercel.
